Personal apps

This page describes a small set of personal-use tools that sign in with Google. They are used only by their owner, on the owner's own devices, and are not offered to the public.

  • File backup — copies the owner's own files to the owner's own Google Drive using rclone.
  • Personal bookkeeping — reads and writes the owner's own Google Sheets.
